# 題庫側邊搜尋

Chrome / Edge Manifest V3 擴充功能。點工具列圖示，在右側開啟面板。頂部有四個獨立頁籤：「題庫網站」顯示原網站、「題庫網站 2」預設顯示使用者提供的課程題庫網址、「本機搜尋」提供截圖辨識與結果、「新增題目」從截圖整理新題並加入本機題庫。內建 439 題演算法與 1015 題作業系統題庫。第二個網站的網址和頁籤名稱可在該頁籤修改，設定存在本機瀏覽器。「本機搜尋」以直式的 OS 與演算法對戰圖作為背景。題庫匯入和網站同步收在頁面下方的「題庫管理」；另行匯入的資料只儲存在本機瀏覽器的擴充功能儲存空間。

## 安裝

1. 開啟 `chrome://extensions`（Edge 使用 `edge://extensions`）。
2. 開啟「開發人員模式」，按「載入未封裝項目」，選擇此資料夾。
3. 在一般網頁按擴充功能圖示。瀏覽器內部頁面不可讀取，請改用手動搜尋。

「本機搜尋」對截圖辨識出的文字進行相似題目比對，結果會顯示科目、網站單元、主題標籤與答案。網站單元依使用者提供的逐單元 HTML 對應；主題標籤取自原網站題卡。演算法第 1 單元及作業系統第 7 單元依其餘單元的互斥題目 ID 和總題數補齊。

## 截圖辨識與快捷鍵

在「本機搜尋」按「擷取目前畫面並搜尋」，可擷取目前分頁的可見畫面；也可以上傳題目截圖。要直接貼圖，先複製截圖，點側欄的貼圖區，再按 `Ctrl+V`（Mac 為 `Command+V`）。擴充功能用打包的繁體中文與英文 OCR 模型在本機辨識，再查題庫。圖片較小或辨識信心低時會自動放大、增強對比並重試；搜尋時優先使用擷取出的題幹，降低選項文字干擾。第一次使用需要載入模型，可能較慢；可展開「查看辨識出的文字」核對結果。辨識不準時請裁切出題目區域後重試。

辨識後會獨立顯示「截圖辨識的題目（不含選項）」和複製按鈕，內容直接來自 OCR 擷取的題幹，即使題庫沒有這題也能複製。若找到高相似度的題庫題目，另行顯示「題庫配對的題目」及其複製按鈕。兩者不互相覆蓋；複製前可在文字框修正錯字。

## 從截圖新增題目

在「新增題目」頁籤擷取目前畫面、貼上或上傳截圖。OCR 會拆出題幹、多行選項與明確標示的正確答案；答案若為 A、C 等代號，會對應到選項文字。中英文冒號、逗號等標點可混用。所有欄位均可修正。截圖沒有標出正確答案時，答案欄保持空白，需人工填寫後才能儲存。可選填科目、網站單元與主題標籤。相同科目及題幹的題目不會重複加入。

新增題目保存在此瀏覽器的擴充功能儲存空間，會參與本機搜尋。按「匯出自行新增的題目 JSON」可備份或提供給其他人匯入。儲存到本機不會修改原題庫網站，也不會自動推送到 GitHub。

預設快捷鍵為 Windows / Linux 的 `Ctrl+Shift+Y`、macOS 的 `Command+Shift+Y`，會擷取畫面並開啟側邊欄。若瀏覽器沒有啟用該組合或與其他快捷鍵衝突，請在 `chrome://extensions/shortcuts` 修改「截圖辨識並在側邊欄搜尋題目」。

開啟原題庫網站 `os-study-notebook.shij.chatgpt.site` 時，已安裝的擴充功能會在網頁右下角加入「截圖辨識題目」按鈕。按下後會開啟側欄的本機搜尋，可貼上或上傳題目截圖。辨識結果中的「在原題庫網站查看這題」會把選中的題目帶回網站搜尋欄。此入口由擴充功能加入，不會修改網站伺服器或讓未安裝擴充功能的訪客看到按鈕。

OCR 使用 Tesseract.js 7.0.0、Tesseract.js Core 7.0.0，以及 `@tesseract.js-data/chi_tra` 與 `@tesseract.js-data/eng` 1.0.0 的模型，隨擴充功能打包。程式授權檔存於 `vendor/ocr/`；辨識時不會把截圖送到外部服務。

如果「題庫網站」是空白或顯示拒絕連線，代表該網站禁止嵌入其他頁面；此限制由網站設定決定。可使用「本機搜尋」或按「在新分頁開啟題庫網站」。

「題庫網站 2」預設網址為 `https://yocheng06.github.io/course-library/submit.html?v=theme-toggle-20261027`。若該網站禁止嵌入，請用頁籤下方的按鈕在新分頁開啟。第二個網站只作為獨立瀏覽頁籤，不會與原題庫的本機資料或同步功能混在一起。

更新擴充功能後，請在 `chrome://extensions` 找到「題庫側邊搜尋」按重新載入，並允許存取 `ccsa.nfu.edu.tw`。如果先前下載的是 ZIP，須重新下載、解壓縮並替換原資料夾，再按重新載入。已匯入的題庫仍保存在瀏覽器擴充功能儲存空間。

## 題庫格式

支援從原題庫網站儲存的 HTML，以及 UTF-8 JSON、CSV、TSV。匯入會合併到現有題庫。JSON/CSV/TSV 欄位可使用 `question` / `題目` / `題幹`，以及 `answer` / `答案` / `正確答案`。JSON 可直接使用陣列，或在物件中放 `questions` / `items` 陣列：

```json
[
  {"question":"線性時間排序算法的共通限制包括？", "answer":"通常有特定的輸入假設"}
]
```

內建題庫取自使用者提供的網站 HTML 快照，共 1454 題，其中包含新提供的作業系統完整頁面新增的 57 題。演算法 4 題、作業系統 9 題未顯示可確認的答案。多選答案會分行顯示。

按「從題庫網站同步最新題目」時，擴充功能會在背景開啟原網站，依序讀取兩科與各單元的題卡，再合併到本機題庫並關閉臨時分頁。第一次使用需允許擴充功能存取 `os-study-notebook.shij.chatgpt.site`。如果網站改版導致同步失敗，仍可匯入儲存的 HTML。同步資料保存在本機；這個功能尚未在使用者瀏覽器中驗證。

## 驗證

在 Chrome / Edge 載入擴充功能後，匯入範例 JSON，開啟含題目文字的網頁，選取題幹並搜尋；面板應顯示相似題目與答案。重新開啟面板後，題庫應保留。
